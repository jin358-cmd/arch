# Simple UI v2 第二批驗收紀錄

## 範圍

本批沿用 `feat/simple-ui-v2`，只調整施工進度、現場管理、專案資料與專案總覽細節。未修改 `main`，未變更 Supabase Schema、RLS、Storage 或 API。

## 現況／調整後

| 頁面 | 調整前 | 調整後 |
| --- | --- | --- |
| 專案總覽 | P0 首頁骨架 | 統一卡片、狀態、留白與手機排列，保留既有資料來源 |
| 施工進度 | 直接進入完整甘特圖，資訊密度較高 | 先顯示目前階段、預定／實際進度、差異、落後項目與下一里程碑；完整甘特圖仍保留 |
| 現場管理 | 需進入廠商流程查找施工小項 | 集中今日施工、施工中、待查驗、待審核及最新紀錄；進度／狀態直接回寫既有施工小項 |
| 專案資料 | 資料入口分散於進階功能 | 集中為圖面、文件、合約、報價、廠商、會議、附件與其他資料八類；既有功能直接連回原入口 |
