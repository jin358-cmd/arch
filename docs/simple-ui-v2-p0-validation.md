# Simple UI V2：第二階段第一批 P0 驗證報告

分支：`feat/simple-ui-v2`

## 完成範圍

- 四大主導航：專案總覽、施工進度、現場管理、專案資料。
- 專案總覽首頁：工程名稱、目前階段、整體完成率、今日施工、進度狀態、待處理、異常／缺失、下一里程碑。
- 第二層「更多／進階功能」：工期與預算、廠商管理、核定審查、跨階段檢核、會議紀錄及專案設定／同步。
- 手機直式基本排版、觸控尺寸及橫向溢出修正。
- 修正廠商流水號在頁面初始化時提早引用自訂廠商函式的執行錯誤。

## Before／After

| Before | After |
| --- | --- |
| 所有功能垂直堆疊在同一首頁 | 首層只保留四個工作入口 |
| 首頁先顯示方案與完整流程 | 首頁先回答階段、今日工作、落後、問題及下一步 |
| 四種進度檢視位於全域操作列 | 收入「施工進度」入口 |
| 工期預算、完整廠商、檢核與會議直接佔首頁 | 收入第二層「更多／進階功能」 |
| 手機版甘特圖區外層可能橫向溢出 | 頁面本身不橫向爆版，甘特圖在自己的容器內捲動 |

## 資料與相容性

- 首頁摘要直接讀取既有專案、排程、施工小項、核定審查及方案鎖定資料。
- 未建立新的專案資料來源，不清除或搬移 localStorage 資料。
- 未修改 Supabase Schema、Migration、RLS、Storage policy、API 或同步鍵。
- 舊甘特圖、看板、日曆、列表、方案、廠商、核定審查、檢核及會議仍可由新入口到達。
- 現場照片及通用文件仍無專用資料模型；第一批僅提供清楚入口與說明，不建立假資料。
