# 新建建築專案工作流程

這是一個單一 HTML 檔案的互動式施工流程管理模板，不需要安裝套件或建置工具。

## 使用方式

1. 下載並解壓縮 ZIP。
2. 以 Chrome、Edge 或其他現代瀏覽器開啟 `index.html`。
3. 排程、進度、廠商工作日、施工小項與自訂會議資料保存在目前瀏覽器；會議附件使用瀏覽器的 IndexedDB 儲存空間。

## 主要功能

- 土地開發、建照規劃、室內協作與施工執行四階段流程。
- 甘特圖、看板、列表及日曆四種工作進度檢視；甘特圖支援複選階段並同時顯示多項進度。
- 標準工期、最短工期、基本預算及最少預算四種方案模式。
- 可修改基本工程預算，預覽各方案工期、工日與階段預算。
- 可設定工期起始日；若選到週末，系統會自動調整為下一個工作日，並重新順排全部工作日期。
- 切換方案、修改工期起始日或基本工程預算時，工作時數、日期、階段／工作預算、甘特圖及廠商工作日會立即同步。
- 可「確認並鎖定方案」；鎖定後方案、工期基準起始日、基本預算、預估工時與廠商工作日會保留為核定基準，各工作項目、施工小項及同項小項的執行起迄日期時間仍可調整。
- 主工作項目會保留鎖定時的基準日期，調整執行日期後自動標示開始與結束日期提前／延後天數，並同步更新甘特圖及日曆。
- 整合 24 個月 RC 新建實務基準：33 道標準關卡，可依階段篩選並記錄未開始、進行中、待審查與已完成狀態。
- 每道標準關卡均對應工作項目與協作廠商，顯示同步日期、工時、預算、工作進度、廠商平均進度與工日。
- 標準關卡、工作項目與協作廠商進度雙向同步；從任一區塊調整進度，另外兩區會自動回寫。
- 送照前 I5 強制關卡包含 10 項建築／室內衝突檢核，檢核完成比例會同步到工作項目與對應廠商。
- 7 場固定施工協調會議，內含時機、出席人員、標準議程、應產出，以及可編輯的日期時間、狀態與決議紀錄；會議狀態同步施工關卡。
- 可另外新增、編輯或刪除自訂施工會議；「新增會議」採頁面內輸入視窗，不依賴瀏覽器原生提示框，並依專案保存會議名稱、時機、出席對象、議程、預定產出與會議紀錄。
- 每場會議可上傳多個附件（單檔上限 20 MB）、下載或刪除；附件依目前網站、專案及會議分開保存於同一瀏覽器，不會自動同步至其他裝置或不同網址。
- 可填寫訊息稱呼與 e-mail 收件人；LINE 按鍵會帶入會議行程並開啟 LINE 官方對象選擇流程（電腦版先進入 LINE 網頁登入，手機版開啟 LINE App），由使用者選擇好友／群組；靜態網站本身不會讀取 LINE 聯絡人。Gmail 按鍵會使用目前登入的 Gmail 帳號開啟撰寫頁，自動填入收件人、主旨與會議內容，最後由使用者確認傳送。
- 瀏覽器安全限制下，LINE／e-mail 無法自動夾帶本機附件；訊息會列出附件名稱，寄送前需手動夾帶檔案。
- 由土地開發、專業技師到竣工點交共 52 類協作廠商／角色與建議工作日。
- 每家廠商可展開並新增、編輯施工小項、次欄位、進度、狀態、起迄日期時間及查驗紀錄。
- 施工小項最前方以兩個獨立欄位顯示自動順序編號與收合按鍵，刪除按鍵置於最右欄；進度與狀態採精簡欄寬，起迄日期時間以上下排列並以整點小時填寫。
- 每個施工小項內可再新增多筆「同項小項」，分別記錄名稱、進度、狀態、起迄日期時間及施工說明，子項平均進度會自動回算父項與廠商進度。
- 已完成項目使用橘色區塊及完成標示。
- 「新案登錄」採頁面內輸入視窗，可建立乾淨的新建案並輸入專案名稱；建立後會以新案起始日、標準工期及基本工程預算重新計算四種工期與預算方案、工作排程及廠商工日；既有瀏覽器資料第一次使用時會自動登錄為「既有專案」。
- 「儲存專案」會保存目前專案的方案、排程、進度、廠商、小項、查驗與會議資料；「專案命名」可修改名稱。
- 已儲存專案會出現在下拉選單中，可切換並繼續編輯；切換前系統會自動保存目前專案。

## 預算說明

頁面中的基本工程預算是可修改的規劃範例，不含土地取得、稅費、融資、物價波動及專案特殊條件，不能取代建築師、營造廠或估價顧問的正式報價。

## 部署

將 `index.html` 放入任何靜態網站空間即可部署，例如 GitHub Pages、Cloudflare Pages 或一般網站主機。
