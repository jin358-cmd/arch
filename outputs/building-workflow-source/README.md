# 新建建築專案工作流程

這是一個單一 HTML 檔案的互動式施工流程管理模板，不需要安裝套件或建置工具。

## 使用方式

1. 下載並解壓縮 ZIP。
2. 以 Chrome、Edge 或其他現代瀏覽器開啟 `index.html`。
3. 排程、進度、廠商工作日、施工小項與自訂會議資料保存在目前瀏覽器；會議附件使用瀏覽器的 IndexedDB 儲存空間。

## 主要功能

- 「土地開發與可行性」、「建築規劃與建照」、「室內設計協作檢討」及「施工協調與工班執行」四階段流程；上方分頁、PHASE 01–04、標準實務執行細節與施工流程篩選均使用相同階段名稱。
- 後台預設以甘特圖作為整體主檢視；甘特圖採三層收合架構：第一層為 12 個主項目進度、第二層為 33 道標準順序流程、第三層為各流程對應的施工協作廠商／工種。
- 點擊主項目可展開所屬流程小項，再點擊流程小項可展開協作廠商；第一至三層均可新增階段工作項目、流程及協作廠商／工種。自訂第二層流程可再次編輯，點擊主責／會簽可直接前往該流程的協作廠商。方案鎖定後仍可追加，系統會保留鎖定基準並從原完工日接續排程，同步增加總工時及更新完工日。
- 「核定審查、檢核與會議紀錄」提供主項目的核定審查分頁，並可選擇歸屬工作項目新增核定項目；審查日期、審查狀態及審查意見／改善措施與列表檢視共用資料，任一處修改後會同步反映。
- 「檢視方式」已移至上方固定操作列最左側，依序提供甘特圖（預設）、看板、日曆及列表四種檢視；四個階段可在所有檢視模式複選；由「全部」首次點選單一階段時會只顯示該階段，並同步篩選標準關卡、衝突檢核、會議與相關協作廠商／工種。操作列採雙列配置，所有階段分頁名稱可直接完整檢視，不需左右滑動。
- 標準工期、最短工期、基本預算及最少預算四種方案模式。
- 工期與預算方案未鎖定前預設展開且可手動收合；方案套用並鎖定後會固定閉合且不可再展開，重新載入或切換至已鎖定專案時亦保持閉合。
- 基本工程預算以「新台幣／萬元」輸入與顯示，可預覽各方案工期、工日與階段預算。
- 可設定工期起始日；若選到週末，系統會自動調整為下一個工作日，並重新順排全部工作日期。
- 切換方案、修改工期起始日或基本工程預算時，可先預覽工作時數、日期、階段／工作預算、甘特圖及廠商工作日。
- 按下「套用此方案至排程並鎖定」後，方案、工期基準起始日、基本預算、預估工時與廠商工作日會保留為核定基準；所有施工小項及同項小項會依對應工種與方案工期排入開始／結束日期，並鎖定日期欄位。進度、狀態與查驗紀錄仍可持續更新。
- 主工作項目會保留鎖定時的基準日期，調整執行日期後自動標示開始與結束日期提前／延後天數，並同步更新甘特圖及日曆。
- 整合 24 個月 RC 新建實務基準：33 道標準關卡均依資料對應至 12 個主項目，可依階段篩選並記錄未開始、進行中、待審查與已完成狀態。
- 每道標準關卡均對應工作項目與協作廠商，顯示同步日期、工時、預算、工作進度、廠商工日加權進度與工日。
- 標準關卡、項目進度審核與施工協作廠商流程進度雙向同步；從任一區塊調整進度，另外兩區會自動回寫。
- 四個標準階段共提供 30 項跨階段衝突檢核，完成比例會同步到各階段代表關卡、工作項目與對應廠商；新增檢核點時可由下拉選單指定歸屬區塊／工作項目，亦可刪除自訂檢核點。
- 7 場固定施工協調會議，內含時機、出席人員、標準議程、應產出，以及可編輯的日期時間、狀態與決議紀錄；會議狀態同步施工關卡。
- 可另外新增、編輯或刪除自訂施工會議；「新增會議」採頁面內輸入視窗，不依賴瀏覽器原生提示框，並依專案保存會議名稱、時機、出席對象、議程、預定產出與會議紀錄。
- 每場會議可上傳多個附件（單檔上限 20 MB）、下載或刪除；附件依目前網站、專案及會議分開保存於同一瀏覽器，不會自動同步至其他裝置或不同網址。
- 可填寫訊息稱呼與 e-mail 收件人；LINE 按鍵會帶入會議行程並開啟 LINE 官方對象選擇流程（電腦版先進入 LINE 網頁登入，手機版開啟 LINE App），由使用者選擇好友／群組；靜態網站本身不會讀取 LINE 聯絡人。
- Gmail 附件交接會優先使用瀏覽器的檔案分享功能，於支援裝置選擇 Gmail 後可連同附件移轉；不支援檔案分享時，系統會先下載附件並開啟已填妥收件人、主旨與內容的 Gmail 撰寫頁，使用者只需將下載檔拖入郵件。Gmail 網頁基於安全限制，不允許一般靜態網站直接寫入其附件欄位。
- 由土地開發、專業技師到竣工點交共 52 類預設協作廠商／角色與建議工作日，已完整對應到甘特圖的 33 道流程小項；自訂新增廠商亦會同步出現在甘特圖與下方施工協作廠商明細表。
- 廠商順序統一顯示為 `#01` 起的數字編號，自訂廠商由 `#53` 接續；九種工種階段使用不同色塊，方便在甘特圖及廠商明細中辨識。
- 新增階段工作項目、流程、廠商、施工小項或同項小項時均可輸入工作日，最小單位為 `0.125` 日（1 小時）；系統依工作日自動重算點選層級的比例分配與執行進度，並逐層同步至廠商、流程、主項目及專案加權進度。
- 每家廠商可展開並新增、編輯施工小項、次欄位、進度、狀態、起迄日期時間及查驗紀錄。
- 新增的施工小項與既有小項使用相同欄位格式；欄位內容置中，最前方自動順序編號與收合按鍵會對齊上方欄名，刪除按鍵置於最右欄；進度與狀態採精簡欄寬，起迄日期時間以上下排列並以整點小時填寫。
- 每個施工小項內可再新增多筆「同項小項」，分別記錄名稱、工作日、進度、狀態、起迄日期時間及施工說明，子項會依工作日比例自動回算父項與廠商進度。
- 方案尚未鎖定時，已完成項目維持橘色區塊；方案鎖定後會依核定期限判定，期限內完成顯示藍色，逾期完成或已超出預定時間顯示紅色，並同步套用至列表、甘特圖、看板、日曆及施工協作廠商流程。
- 「新案登錄」採頁面內輸入視窗，可建立乾淨的新建案並輸入專案名稱；建立後會以新案起始日、標準工期及基本工程預算重新計算四種工期與預算方案、工作排程及廠商工日；既有瀏覽器資料第一次使用時會自動登錄為「既有專案」。
- 頁面右上方整合精簡的專案控制列，移除「目前專案」文字區塊，直接保留已儲存專案下拉選單、儲存與命名功能。
- 「儲存」會保存目前專案的方案、排程、進度、廠商、小項、查驗與會議資料；已儲存專案會出現在切換選單中，切換前系統會自動保存目前專案。

## 預算說明

頁面中的基本工程預算是可修改的規劃範例，不含土地取得、稅費、融資、物價波動及專案特殊條件，不能取代建築師、營造廠或估價顧問的正式報價。

## 部署

將 `index.html` 放入任何靜態網站空間即可部署，例如 GitHub Pages、Cloudflare Pages 或一般網站主機。
